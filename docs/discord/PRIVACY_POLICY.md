# AetherXIV — Discord Rich Presence Application Privacy Policy

*Last updated: August 13, 2026*

This policy describes how the AetherXIV Discord Rich Presence application
("Final Fantasy XIV 1.X") handles information. AetherXIV is an independent
project and is not affiliated with Square Enix or Discord Inc.

## What this application processes

The Discord Rich Presence application itself sends very little data:

- **To Discord (via your local Discord client):** when you play with the
  feature enabled, the application connects to Discord's local IPC interface on
  your own machine and sends the registered application id, the game process
  id, and the activity text configured by you. This data stays on your machine
  until your local Discord client uploads it to Discord as part of your profile
  status. Discord's own privacy policy applies to that data.
- **To AetherXIV servers: nothing.** The Rich Presence application does not
  send any data to AetherXIV-operated services.

## Other AetherXIV components

The broader AetherXIV launcher may contact AetherXIV-operated update services to
check for launcher, compatibility-runtime, and Umbra framework/plugin updates.
Those requests carry routine connection metadata (such as your IP address) and
the channel/version identifiers needed to serve the correct update. No game,
account, character, or personal profile data is transmitted.

You choose the server your game connects to; login and game data flow to the
server you configure, which is yours or a third party's, not ours.

## Local storage

All configuration (including the Rich Presence application id and activity
text) is stored locally on your machine in the launcher's configuration
directory. You can delete it at any time by disabling the plugin and removing
its configuration folder.

## Contact

For questions about this policy, reach out through the AetherXIV project's
public channels or issue tracker.

## Changes

We may update this policy as the project evolves. Material changes will be
reflected in the "Last updated" date above.
